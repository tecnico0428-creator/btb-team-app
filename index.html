AI 판독 연결

기본 판독은 글자만 읽어서 표 모양이 낯설면 틀릴 수 있습니다. AI를 연결하면 표 구조를 이해해서 더 정확하게 읽습니다. 읽은 결과는 항상 합계 검산과 확인 화면을 거치고, 확인해야 저장됩니다.
구독 중인 AI 계정으로 바로 로그인은 안 되나요?
ChatGPT, 클로드, 제미나이의 월정액 구독 계정으로 다른 앱에 로그인해 쓰는 것은 각 회사 약관상 일반 앱에 열려 있지 않거나 금지되어 있습니다(클로드는 금지, ChatGPT는 승인된 제휴 앱만 가능). 또 구독과 API 키는 요금이 따로입니다. 그래서 아래 두 가지 방법을 제공합니다.
1) 내 AI 앱으로 보내기: 구독 중인 AI 앱을 그대로 쓰는 방법(키 불필요, 사진 보내고 답을 붙여 넣는 과정이 있음)
2) API 키 연결: 한 번 연결하면 자동으로 읽음(키는 이 폰 안에만 저장)
